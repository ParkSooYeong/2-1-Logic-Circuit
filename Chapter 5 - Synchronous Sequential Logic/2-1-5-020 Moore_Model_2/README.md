# Moore Model 2

## Overview
This project implements a **Moore Finite State Machine (FSM)** in Verilog HDL. The FSM consists of four states (`S0`, `S1`, `S2`, `S3`) and transitions to the next state when the input `x_in` is asserted. The output `y_out` is determined solely by the current state, satisfying the Moore machine model.

Two implementations are included:

1. **Behavioral Model** (`Moore_Model_2`)
2. **Structural Model** (`Moore_Model_2_STR`) using T Flip-Flops

Simulation results confirm that both implementations produce identical outputs.

---

## State Diagram

| Current State | x_in = 0 | x_in = 1 | Output |
|--------------|----------|----------|--------|
| S0 | S0 | S1 | 0 |
| S1 | S1 | S2 | 0 |
| S2 | S2 | S3 | 0 |
| S3 | S3 | S0 | 1 |

---

## Design Description

### Inputs

- `clock` : System clock
- `reset` : Active-low asynchronous reset
- `x_in` : State transition control input

### Outputs

- `y_out` : Moore FSM output

### State Encoding

| State | Binary |
|---------|---------|
| S0 | 00 |
| S1 | 01 |
| S2 | 10 |
| S3 | 11 |

The output is asserted only in state `S3`.

| State | y_out |
|---------|--------|
| S0 | 0 |
| S1 | 0 |
| S2 | 0 |
| S3 | 1 |

---

## Behavioral Implementation

The behavioral FSM uses:

- State register updated on the rising edge of `clock`
- Active-low asynchronous reset
- State transition logic implemented with a `case` statement
- Output generated by:

```verilog
assign y_out = (state == S3);
```

---

## Structural Implementation

The structural design realizes the same FSM using two T Flip-Flops.

### Flip-Flop Excitation Equations

```verilog
TA = x_in & B;
TB = x_in;
```

### Output Equation

```verilog
y_out = A & B;
```

where:

- `A` = MSB state bit
- `B` = LSB state bit

The structural implementation follows the same state sequence as the behavioral model.

## Simulation Results

Simulation verified:

- Proper asynchronous reset operation
- Correct state progression when `x_in = 1`
- State hold behavior when `x_in = 0`
- Correct output assertion only in state `S3`
- Equivalent operation of behavioral and structural implementations

### RTL Schematic

The synthesized RTL schematic shows:

- Four-state Moore FSM implementation
- State register with asynchronous reset
- Output logic driven by state decoding
- Correct state transition network

### Timing Waveform Verification

The simulation waveform confirms:

- Reset initializes the FSM to `S0`
- Consecutive assertions of `x_in` advance the state sequence
- State sequence follows:

```text
S0 → S1 → S2 → S3 → S0
```

- `y_out` becomes high only while the FSM remains in `S3`
- Behavioral and structural outputs match throughout simulation
